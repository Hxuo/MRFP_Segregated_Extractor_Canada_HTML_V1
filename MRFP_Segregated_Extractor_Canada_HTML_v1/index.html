About

Independent segregated-fund project. Modular issuer adapters; one document may contain hundreds of funds. MER refers to the exact table column selected by each issuer-specific adapter. TER means Total Expense Ratio only, never Trading Expense Ratio. Values and missing fields are never estimated.
